Album Dock · 만든 사람: 찌모킹

설치
1. Mac의 칩에 맞는 DMG를 받으세요: Apple M 시리즈는 arm64, Intel은 x64입니다.
2. DMG를 열고 Album Dock.app을 Applications 폴더로 드래그하세요.
3. 복사가 끝나면 DMG를 추출하고 응용 프로그램에서 Album Dock을 여세요.
4. 설정에서 음악 저장 폴더를 선택하세요. Python, Node.js, FFmpeg의 별도 설치는 필요 없습니다.

지원 목표: macOS 13 이상. 빌드된 모든 의존성의 최소 OS와 실제 지원 범위는 릴리스 검증 결과를 확인하세요.
현재 설치본은 테스트용이며 Apple Developer ID 서명·공증이 없습니다.
macOS가 실행을 막으면 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 실행 허용 항목을 확인하세요.
보안 기능을 전체 해제할 필요는 없습니다. 일반 배포용 서명·공증은 별도 준비 중입니다.

업데이트
Album Dock을 완전히 종료하고 새 앱으로 교체하세요.
설정과 로그인 정보는 사용자 Application Support 폴더에, 음악은 선택한 저장 폴더에 남습니다.

사용
내 음악에서 커버플로우·격자 보기로 앨범을 탐색할 수 있습니다.
YT Music 로그인은 Google의 내장 브라우저 정책에 따라 제한될 수 있습니다.
아이팟으로의 직접 전송 기능은 아직 없으며 Music/Finder 동기화를 별도로 사용합니다.
